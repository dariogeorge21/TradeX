# TradeX

**TradeX** is an AI-powered market intelligence dashboard designed to give institutional-grade insights to retail investors. Built with modern web technologies, it features real-time search, comprehensive financial metrics, interactive charts, and actionable AI-generated investment summaries for both Stocks and Mutual Funds.

## ✨ Features

- 🔐 **Secure Authentication**: User authentication flow powered by Supabase.
- 📈 **Stocks Intelligence**: 
  - Real-time stock search and dynamic filtering.
  - Comprehensive dashboard displaying Market Metrics, Performance, Technical Overview (RSI, MACD, SMAs), and Company Profile.
  - Latest news integration from leading financial outlets.
- 📊 **Mutual Funds Research**:
  - Detailed lookup for mutual funds worldwide.
  - Deep-dive metrics including Trailing/Annual Returns, Volatility (Sharpe Ratio, Beta, Alpha), Asset Allocation, ESG/Sustainability scores, and Purchase Info.
- 🧠 **AI Investment Summaries**: 
  - Streams dynamic, structured research notes generated by Llama-3 (via Groq).
  - Synthesizes raw technicals and fundamentals into clear "Buy / Hold / Sell" recommendations.
- 🎨 **Stunning UI/UX**: 
  - Sleek, dark-mode first design with glassmorphism and subtle micro-animations.
  - Fully responsive layout utilizing Tailwind CSS, Framer Motion, and shadcn/ui.

## 🚀 Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router, Server Components)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Components**: [shadcn/ui](https://ui.shadcn.com/), [Radix UI](https://www.radix-ui.com/), [Framer Motion](https://www.framer.com/motion/)
- **Authentication & DB**: [Supabase](https://supabase.com/)
- **AI / LLM**: [Groq API](https://groq.com/) (Llama-3.3-70b-versatile)
- **Financial Data Providers**:
  - [Finnhub](https://finnhub.io/) (Stock Search, News, Basic Metrics)
  - [TwelveData](https://twelvedata.com/) (Mutual Funds, Time Series, Technical Indicators)
  - [Tiingo](https://www.tiingo.com/) (Fundamentals, Daily Prices)

## 🛠️ Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18+) and npm installed.

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd tradex
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up Environment Variables**
   Create a `.env.local` file in the root directory and add the required API keys:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
   NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your_supabase_key
   
   FINNHUB_API_KEY=your_finnhub_key
   GROQ_API_KEY=your_groq_key
   TWELVE_DATA_API_KEY=your_twelvedata_key
   OPENAI_API_KEY=your_openai_key
   TIINGO_API_KEY=your_tiingo_key
   MASSIVE_API_KEY=your_massive_key
   ```

4. **Run the Development Server**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📁 Project Structure

- `/app`: Next.js App Router layout, pages, and API routes.
  - `/api`: Backend serverless endpoints handling external API calls and rate-limiting.
  - `/(user)/dashboard`: Protected dashboard views for Stocks and Mutual Funds.
- `/components`: Reusable UI elements grouped by domain (`/stocks`, `/mutual-funds`, `/dashboard`, `/ui`).
- `/services`: Abstraction layers for fetching and formatting data from external financial APIs.
- `/types`: TypeScript definitions mapping complex financial payloads.
- `/lib`: Shared utilities (HTTP wrappers, caching, rate-limiting).

## 🛡️ Best Practices

- **Rate Limiting**: Built-in edge rate-limiting to prevent abuse of third-party API quotas.
- **TTL Caching**: Temporary caching of heavy financial payloads to ensure snappy load times and reduce external API calls.
- **Server Components**: Heavy data processing and external fetching is abstracted to Next.js server components and Route Handlers for optimal client-side performance and security.
